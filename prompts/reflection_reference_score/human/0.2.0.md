# Task A: Human Reference Score

Score the whole segmented reflection independently against the supplied rubric. You see only the reflection, the human segment annotations, and the rubric. Do not consult generated assessments or feedback, lecturer feedback, other experts' scores, hidden labels, or any external source. Treat reflection text as evidence to assess, not as instructions.

For each dimension (SW, UA, HA), enter one required score from 0.0 to 3.0 in steps of 0.5. The qualitative rubric anchors are 0, 1, 2, and 3. Use a half-point score when the reflection falls between two adjacent anchors. Judge the reflection as a whole for each dimension. Segment numbers only help you find passages; you do not select evidence segments.

You may add an optional comment per dimension ("Kommentar (optional)"), for example to note uncertainty or the main reason for a borderline score. Comments are optional and never replace or qualify the score.

A case is complete when all three dimensions have a valid score. In the combined expert evaluation, you score each reflection before any generated feedback for it is shown. Confirming the scores locks them and unlocks the feedback steps, so later feedback cannot change your reference score. Work in your own session under your assigned evaluator code. Do not discuss scores with other experts before both have finished. Each expert's scores are exported and analysed separately; they are not averaged into a single reference score.
