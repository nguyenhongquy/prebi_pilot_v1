# Feedback-Implied Rubric Score Coding Protocol 0.1.0 (Development Draft)

Status: development draft. Calibrate and revise using development examples only; freeze a version before applying it to confirmatory data.

## Purpose and interpretation

Record what score, if any, is reasonably implied by existing human feedback when read with its rubric and reflection context. This is an inferred score expressed by the feedback, not an independent expert judgment of the learner's actual performance and not a gold reference score.

## Materials

Use the original segmented reflection, segment IDs, rubric version and anchors, and the associated human feedback. Do not use G1/G2/G3 outputs or generated ratings to infer the score. Keep the feedback source and rubric version attached to the coding record.

## Procedure for each rubric dimension (SW, UA, HA)

1. Decide inferability first. If the feedback does not communicate a defensible dimension-specific score or level, select `not_inferable`; do not guess from tone or general praise/criticism.
2. If inferable, assign a raw score from 0.0 to 3.0 in 0.1 increments, anchored to the rubric's whole-band descriptions. Do not round to a half-band during coding.
3. Record confidence (`low`, `medium`, `high`), a concise rationale, and the exact feedback evidence. Where possible, anchor evidence to a feedback span using zero-based, end-exclusive character offsets in the immutable feedback text.
4. Keep dimensions separate. Do not invent an overall score or infer a missing dimension from another dimension.

## Coding values

- `status`: `inferred_from_feedback` or `not_inferable`.
- `score`: numeric 0.0-3.0 in tenths only when inferred; otherwise null.
- `confidence`: low/medium/high for an inferred score; `not_inferable` otherwise.
- `feedback_evidence`: one or more quoted spans or exact offsets supporting the inference; empty only when not inferable.
- `rationale`: explain the rubric link and why the evidence supports the coded value, or why feedback is insufficient.

## Important cautions

- Do not convert missing or ambiguous feedback to 0.
- Distinguish a score explicitly stated in feedback from a score inferred from descriptive language; record that distinction in the rationale.
- Preserve the raw tenth-level score. Half-band summaries (for example 2.0, 2.5, 3.0) are derived later using a documented rounding rule.
- Store these as secondary, inferred labels. They must never replace independently expert-scored reference assessments.
- Keep independent coder judgments; resolve disagreements in a separate adjudication record rather than overwriting originals.
